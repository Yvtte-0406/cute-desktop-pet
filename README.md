# 阿泠 · 白色九尾狐桌宠

一个尽量不分散注意力、帮你记住重要事项的 Windows 静音桌宠。阿泠会陪你工作和学习，以活泼俏皮、带一点点小傲娇的口吻提醒你。

## 本地新版功能

### 桌宠交互

- 待机、眨眼、静音说话、点击抚摸和拖拽托起；九条完整尾巴同步收拢与展开，保留身体惯性和动态遮挡。
- 右键打开圆弧菜单：待办、大小、设置、退出。
- 大小支持 40%–150%，自动保存；透明区域可点击到下方桌面。
- 单实例运行，重复打开会显示已有桌宠；设置中支持 Windows 开机自启。

### 简洁的事项页面

待办面板分为两个页面：

- **添加事项**：填写名称、勾选是否每日重复、选填截止时间。
- **现有事项**：显示类型、当前状态和相关时间，每条只提供“修改”“删除”。

类型与状态直接显示，例如“单次 · 待完成”“每日 · 今日已完成”。每日完成后仍留在同一列表，不另设“已结束 / 旧记录”分类。

| 类型 | 适用事项 | 点击完成后 |
| --- | --- | --- |
| 单次 | 作业提交、缴费、预约等 | 移出清单，保留 10 秒撤销机会 |
| 每日 | 校园跑、每日自学、复习等 | 只完成当天，当天不再提醒，下一天继续 |

新建每日事项默认上午 9 点提醒；若填写的每日截止时间更早，提醒时间相应提前。已有每日事项沿用原先保存的时间。单次事项填写具体日期和时间，每日事项可填写当天的截止时刻。

每日状态按电脑本地日期切换，不按“完成后 24 小时”计算。跨零点只更新状态，不在零点弹出提醒；漏做不会累积补弹过去几天的事项。

### 提醒与反馈

每次只展示一件事。提醒气泡提供三个反馈选项：

| 选项 | 行为 |
| --- | --- |
| 正在做 | 暂停普通提醒，默认 45 分钟后跟进；可调整时长 |
| 稍后提醒 | 选择时间按钮或自选时间；每日事项的延后只影响当天 |
| 已完成 / 今日完成 | 单次事项移除；每日事项仅完成当天 |

- 未回应的事项正文不因等待、鼠标移动或单纯失焦而自动消失，也不会被晚到的 AI 回复替换。
- 多件事项逐件展示，不使用任务选择下拉框。
- 点击狐狸和对话框之外的位置可收起对话，只留下狐狸；收起不算完成，也不立即弹出下一件。
- 点击狐狸可恢复刚才收起、未回应的提醒；右键气泡文字或空白处也可收起。
- 昨天的气泡留到今天再点击完成，只记到原来的日期，不误把今天也完成。

截止时间、任务状态、去重、每日重置和重启恢复由本地规则处理。AI 不决定硬截止，也不能覆盖用户的按钮选择。

### 离开电脑与恢复

本地结合锁屏、息屏、睡眠和输入空闲状态决定何时展示提醒：

- 锁屏、息屏或睡眠时暂停显示，保留当前阅读和时间选择草稿。
- 恢复后结合实际输入判断是否回到电脑旁，再展示应提醒的事项。
- 键鼠长时间无操作只表示“可能离开”，不等同于锁屏。
- 电脑关机或睡眠期间无法实时提醒；启动或恢复后处理仍有效的事项。

### 可选的 DeepSeek 对话提醒

在设置中填写自己的 DeepSeek API Key，并启用 AI 理解待办。未启用、断网、超时或达到额度时，仍由本地规则提供提醒。

- 使用 `deepseek-flash`。先理解任务含义，再生成自然提醒和按钮回应，避免固定模板机械复述任务标题。
- 一次最多为 8 件相关事项分别准备文案，按事项、修改版本和时间阶段缓存；最近实际展示的话和按钮反馈用于承接对话。
- 普通提醒最多等待约 4 秒准备文案，临近关键截止时立即使用本地保障；晚到的 AI 结果只缓存，不改正在阅读的文字。
- 日期检查和本地计时不调用 AI。默认每天最多 60 次请求，20 次提示用量；失败也计入请求次数。
- 可设置每日请求上限，以及月预算和输入、输出价格。预算为按所填价格计算的估算，实际费用以 DeepSeek 账单为准。

## 数据与隐私

本地用户数据目录：

```text
%APPDATA%\white-fox-desktop-pet
```

- `reminders-v2.json`：事项、提醒及每日状态。
- `reminder-view.json`：当前阅读、收起状态和选择草稿。
- `preferences.json`：桌宠偏好设置。
- `ai-settings.json`、`ai-reminder-state.json`：AI 设置、加密密钥、缓存和用量。
- `todos.json`：保留的旧事项文件，仅用于首次迁移。

API Key 通过 Electron `safeStorage` 使用 Windows 系统能力加密保存。启用 AI 后，相关事项内容、所填时间与工作量、最近按钮反馈和必要时间上下文会发送给 DeepSeek；密钥用于接口认证。

不读取屏幕内容、键盘文本或私人日程。外部点击识别仅在气泡和窗口可见时临时启用：鼠标按下位置在本机助手内瞬时判断，主程序只收到“是否点在外部”的信号，不保存轨迹、不上传位置；气泡收起、窗口隐藏或最小化后停止。

用户事项、密钥、缓存、依赖和构建产物不应提交到仓库。

## 运行与打包

### 当前 GitHub 源码（0.4.3）

在 Windows 上安装 Node.js 和 npm 后：

```powershell
npm ci
npm start
```

构建可独立运行的 Windows 程序：

```powershell
npm run package
```

当前默认分支的输出为：

```text
dist/win-unpacked/阿泠.exe
```

此分支提供基础动画、拖拽、大小调节和早期本地待办提醒；不包含上文全部 0.6.x 新功能。

### 本地新版（0.6.8，待同步源码）

本地新版使用相同的安装、运行与打包命令，输出为：

```text
dist/v0.6.8/win-unpacked/阿泠.exe
```

运行打包版无需安装 Node.js。请保留整个 `win-unpacked` 文件夹，不能只复制 exe；可为其中的程序创建桌面快捷方式。

阿泠是独立应用，正常使用不需要 ChatGPT / Codex 保持打开，AI 提醒直接连接 DeepSeek。建议从桌面快捷方式启动。此前曾出现退出现象，尚未确定是否与开发工具重启、启动环境清理有关；目前没有完善的退出原因日志，不能将该原因视为已证实。
