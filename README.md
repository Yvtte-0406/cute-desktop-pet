# 白狐桌宠 · Windows 本地版

双击 `启动桌宠.cmd` 运行透明桌宠；双击 `预览动画.cmd` 在有背景的窗口中预览。

- 待机：轻微呼吸、尾部摆动、间歇眨眼。
- 左键点击：参考原图的弯弯笑眼、轻歪头与耳朵下垂，脸型保持不变。
- 按住左键拖动：身体悬起，头、耳朵、铃铛、尾巴随拖拽产生惯性联动；松开逐渐回稳。
- 右键点击狐狸：上方弧形图标栏；点击“动作、待办、大小、提醒”展开对应详情，详情位于图标栏上方。退出图标可直接关闭桌宠。
- 展开详情时若屏幕空间不足，暂时缩小显示，为菜单留出空间；收起后恢复用户设置的大小。
- 狐狸下方没有提示文字。透明区域使用 Windows 原生窗口轮廓穿透，可点击下方桌面；狐狸和菜单控件保留交互。
- 大小滑块：60%–150%，上限根据当前屏幕可用空间调整；自动保存，也可恢复默认。
- 说话：静音文字气泡配合口型变化。
- 待办：添加、勾选、删除；每15分钟在待机时提醒未完成事项。可在当前运行期间关闭提醒。
- 任务数据保存在 Windows 当前用户的应用数据目录，不读取屏幕或其他个人文件，不调用外部服务。

首次开发安装：`npm install`，随后 `npm start`。此版本需要 Node.js，不是独立安装包。

`assets/fox.png` 是用户确认的形象参考。实际播放使用 `assets/layers/body.png` 和 `tail-01.png` 至 `tail-09.png`，九条尾巴分别加载、绑定和绘制，每条有自己的摆动相位。

闭眼仅从 `assets/layers/closed-reference.png` 取局部笑眼，固定在原有眼睛位置连续过渡；耳朵绕耳根下垂，活动范围不扩散到脸部。脸型、脸颊轮廓、花钿、鼻嘴及原有腮红保持不变，不再放大或替换整片面部。尾巴从确认原图的可见毛发拆分，保留原位置、宽度与尾尖轮廓，没有统一长条拉伸。

身体仍使用正面立绘的二维绑定，尚不支持大角度转身。预览录像位于 `previews/continuous-animation.webm`，闭眼近图为 `previews/closed-face.png`，菜单近图为 `previews/arc-menu.png`。运行检查：`npm test`。
