# 白狐桌宠 · Windows 本地版

双击桌面的「白狐桌宠」狐狸图标即可打开。程序位于 `dist/win-unpacked/白狐桌宠.exe`，无需另装 Node.js 或运行命令窗口。请保留整个 `win-unpacked` 文件夹，不能只移动其中的 exe。重复打开图标会显示已有桌宠。

- 左键点击抚摸，按住拖动托起，松开自然回稳。全程静音。
- 右键打开狐狸上方的弧形菜单，只有「待办、大小、退出」。菜单靠近狐狸，展开及收起时不移动或缩放狐狸。
- 待办填写事项，可选截止日期和时间；已添加事项只提供删除按钮。旧版任务与已完成记录仍可读取。
- 在待办栏勾选「每30分钟提醒待办」，待机时弹出文字提醒，优先列出较早截止的事项。开关自动保存。截止时间用于显示和提醒排序，目前不是精确到点闹钟。
- 大小为40%–150%，默认基准宽度从440降为300；相同百分比比旧版小约32%。根据屏幕可用空间限制上限，自动保存。
- 透明区域可点击到桌面；菜单、狐狸及文字气泡保留操作。
- 待办与设置保存在当前用户 `%APPDATA%/white-fox-desktop-pet`。数据只保存在本地，不读取屏幕或其他个人文件。

已确认的形象与动画保持：纯白蓬松九尾、雾紫色眼睛及花钿、软绳悬挂一个银铃；连续眨眼、笑眼和耳朵下垂，脸型不随闭眼变形。九条尾巴独立运动并保留原图尾尖。

尚未加入开机自启动。身体为二维绑定，暂不支持大角度转身。

## 开发与打包

`npm ci` 安装依赖，`npm start` 调试，`npm run check` 和 `npm test` 检查，`npm run package` 生成带狐狸图标的Windows程序。`启动桌宠.cmd`、`预览动画.cmd`仅供源码开发时使用。

自动检查涵盖连续动作、脸部轮廓、待办与截止时间保存、30分钟计时、提醒设置保存、尺寸及菜单位置。原生鼠标测试见 `verify-native.cjs`，辅助测试窗口应为普通窗口，避免置顶干扰桌宠。
