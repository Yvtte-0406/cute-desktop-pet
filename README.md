# 阿泠 · 白色九尾狐桌宠

阿泠是Windows本地静音桌宠，用于陪伴和待办提醒。形象为纯白蓬松九尾狐、雾紫色眼睛与花钿、软绳悬挂一枚银铃。

![阿泠的笑眼](previews/closed-face.png)

## 已实现

- 连续待机、眨眼、静音说话、点击抚摸和拖拽托起；闭眼保留原有脸型。
- 九条尾巴先补画完整，再按独立周期与相位绕尾根旋转，保持蓬松宽度和尾尖形状；接触阴影随动作变化。
- 右键打开狐狸上方的弧形菜单：待办、大小、退出；展开时不移动或缩放狐狸。
- 待办填写事项和选填截止时间，已添加事项只提供删除。可勾选每30分钟提醒，使用活泼文案并优先列出较早截止事项。
- 大小范围40%–150%，自动保存；透明区域能点击到下方桌面。
- 内置单实例运行，重复打开会显示现有桌宠。

没有养成、换装或小游戏；不读取屏幕、个人文件或私人日程。没有配置模型API，也没有AI判断紧急程度的功能。提醒目前由本地逻辑运行，无API费用。日期问候、农历节气提示和硬编码节假日均已移除。

## 运行与打包

此仓库提供源码。Windows上安装Node.js和npm后：

```powershell
npm ci
npm start
```

构建可独立运行的Windows程序：

```powershell
npm run package
```

构建完成后双击 `dist/win-unpacked/阿泠.exe`。运行打包版无需另装Node.js。请保留整个 `win-unpacked` 文件夹，不能只复制其中的exe；可自行创建桌面快捷方式。依赖、构建产物和用户任务不提交到仓库。

待办与设置保存在当前用户 `%APPDATA%/white-fox-desktop-pet`，应用改名不会清空已有数据。尚未加入开机自启动。

## Windows时间设置只读识别

独立工具 `tools/inspect-system-time.ps1` 使用Windows NLS及系统时区接口，读取当前用户的区域、默认历法、日期/时间格式和每周起始日；结果输出为JSON，不修改设置，不使用在线服务或固定年份日历。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/inspect-system-time.ps1
```

这是诊断工具，尚未集成进桌宠。默认历法与任务栏附加日历不是同一设置；无法读出的附加日历或节假日数据不会被假定为已识别。

## 当前已确认版本 0.4.2

加载 assets/tails-overlap-v2 中九条补画完整的尾巴，编号沿用用户标注。5号在4号前、左耳后段属于5号；1号尾根在2号前。每条尾巴独立设置周期、相位和轻摆幅度，整体旋转保留原有宽度与蓬松轮廓。待机、说话、抚摸与托起沿用已确认的连续表情和身体动作。

尾巴之间的柔和接触投影由绘图程序根据双方当前姿态实时采样，避免阴影固定在旧位置。不逐帧重新上传图片；启动时加载身体、九尾和闭眼参考，共11张纹理。旧尾巴碎片和旧重绘试稿不参与运行或打包。

20秒预览：previews/overlap-animation-v042.mp4（依次待机、说话、抚摸、托起、回到待机）。此版本已获用户确认，旧尾巴稿和旧动画预览已移入回收站。

## 0.4.3 拖拽长按修复

Windows缩放环境下，原实现每16毫秒重复调用setPosition，鼠标静止时也会反复取回并写入窗口尺寸，导致窗口高度累积增长，底部对齐的狐狸随之下移。现在仅在鼠标坐标变化时更新位置，并始终使用拖拽开始时捕获的宽高。动画参数保持0.4.2的已确认效果，待办数据和设置沿用原目录。

验证：16项自动测试；实际透明窗口在40%、70%、120%对应大小下，各测试原地按住、移动后停住、返回和松手，固定坐标期间窗口位置及宽高的变化均为0；动画、菜单、大小调节、待办和透明区域命中检查通过。

复查窗口拖拽（独立QA数据，不占用鼠标）：

```powershell
npx electron . --qa --window-drag
```

记录输出到qa/window-drag.json；动画回归使用npx electron . --qa --preview。QA数据和用户待办不会上传。
