# 桌宠当前需求与实现

- Windows 本地部署，全程静音；陪伴、待办提醒，不做养成、换装或小游戏。不读取屏幕或其他个人文件。
- 用户确认形象：纯白九尾狐、雾紫色眼睛与花钿、软绳挂一个银铃，铃铛自然落在胸前。
- 闭眼只取参考的局部弯弯笑眼，固定于原眼睛位置连续过渡。耳朵随闭眼下垂，耳根权重收束，不牵动脸部。脸型、脸颊轮廓、花钿、鼻嘴、原有腮红保持不变，禁止整脸替换、放大或变形。五档冻结姿态检查：眼区外面部像素差异为0，脸部透明轮廓差异为0。
- 九条尾巴按确认原图的可见像素拆分，保留宽度、毛发与尾尖外轮廓；尾根由身体遮挡，各自有摆动相位、频率及拖拽响应。不再重画尾尖或拉成统一长条。
- 拖拽：身体整体悬起，头部反向滞后、耳朵放松、铃铛及尾巴跟随摆动；松手后弹簧阻尼回稳。取消旧版前腿局部挤压，腿爪连接完整。
- 右键菜单新增大小滑块：60%–150%，大尺寸会受屏幕可用空间限制；保存后重启保留；可恢复默认。
- 右键打开狐狸上方弧形图标栏，按图标展开更上方的详情；移除狐狸下方提示文字。展开详情时空间不足会暂时缩小狐狸显示，收起后恢复原设置。
- Windows 原生窗口轮廓排除透明区域，保留狐狸、菜单和文字气泡的可见区域；透明处可点击到下方桌面。
- 待办支持用户录入、完成、删除；待机每15分钟文字气泡提醒，可在当前运行中关闭提醒。
