# 当前实现（0.2.0）

- Windows 本地静音陪伴、工作待办提醒，无养成、换装或小游戏。
- 纯白九尾狐、雾紫色眼睛和花钿、软绳挂一个银铃，自然落在胸前。
- 保留已确认的连续动画。闭眼只改变眼睛及耳朵，眼区外面部像素与脸部透明轮廓均保持不变；九尾保留原图毛发与尾尖。
- 右键闪动原因：旧版为菜单动态调整窗口大小和位置，同时调整狐狸显示大小，透明轮廓异步更新。现改为预留菜单区域，展开时不调整窗口及狐狸尺寸。
- 弧形菜单靠近狐狸，保留待办、大小、退出；动作栏及独立提醒栏移除。
- 待办含事项和选填截止时间，事项列表只保留删除。提醒开关位于待办内，每30分钟在待机时提醒，设置持久化。临时互动或菜单打开会推迟到恢复待机时提醒；从休眠恢复后不会连续补发多条。
- 截止时间用于显示和排序，不作为到点闹钟。旧版已完成标记保留且不提醒。
- 基准宽度从440降为300，范围40%–150%，上限随屏幕可用空间调整。
- 独立exe与桌面狐狸快捷图标，不需命令窗口或外装Node.js；重复启动只显示现有桌宠。尚未配置开机自启动。
- 不读取屏幕或其他个人文件，不调用外部服务。正式程序沿用原先的数据目录，打包启动检查使用隔离测试目录。

## 本轮验证

- 10项自动测试与语法检查通过。
- 界面检查：事项、可选ddl、删除按钮、提醒开关保存、30分钟模拟计时、菜单及透明点击逻辑通过。
- 五档闭眼与固定脸型回归通过；九尾抽样12014个毛发像素与原图无差异。
- 原生实测：透明点击到达下层窗口；狐狸点击触发抚摸且下层不接收；真实右键打开菜单，展开详情及收起均无窗口位移、尺寸变化或狐狸画面变化。
- 打包程序启动检查：packaged=true，ready=true，tailCount=9，errors=[]。
