# 0.4.3 长按下滑排查

修复前，在本机Windows缩放环境中，鼠标停止移动、保持托起时，窗口y不变，但高度从638增加到738 DIP；狐狸使用底部对齐，因此发生视觉下滑。原来的16ms定时器即使鼠标不动也反复调用setPosition，在原生像素和DIP之间取整时尺寸累积变化。

修复将原始宽高和坐标在拖拽开始时固定，鼠标坐标改变后才调用setBounds；停住时不再写窗口几何。drag-window.cjs只计算窗口位置，未修改表情、九尾摆幅、拖拽姿态、菜单、待办或透明区域形状。

验证：

- 16项自动测试，包括静止1000次不产生更新、绝对位移、不累积宽高及新的拖拽会话。
- 使用同一生产拖拽控制器与真实透明BrowserWindow，通过固定测试坐标验证40%、70%、120%对应的三种窗口尺寸。每种尺寸覆盖4个静止阶段，每阶段40次采样；x、y、宽、高变化均为0，移动及停止拖拽也通过。此测试不占用系统鼠标。
- 完整动画回归覆盖九尾连通、接缝、阴影、固定脸型、托起边界、点击抚摸、菜单、大小调节、待办存储/提醒及透明区域命中。

本地详细记录在qa/window-drag.json、qa/verification.json。最初的真实鼠标复测受到额外鼠标移动干扰，因此不将该轮判为通过；最终采用固定坐标测试。
